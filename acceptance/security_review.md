# LocalDocMask 安全审查报告

审查日期：2026-10-25（同一执行主体的独立复查）

## 数据流与网络边界

- 输入文件 → 只读打开（各处理器只读源文件，输出写到独立 staging 目录）→ 处理 → 独立审计 → 通过则复制到 output，否则移到 quarantine。
- 本地模型：仅 ollama.py 发起请求，强制校验目标为 127.0.0.1/localhost/::1，Session 已 trust_env=False 且 proxies 置空，绝不走系统代理。
- 全文代码检索确认：除 ollama.py 外无任何 requests/urllib/httpx/socket 等网络客户端；无 telemetry/sentry/云端 API。
- OCR：RapidOCR 本地离线推理，模型内置，无外联。
- 外部资源：无远程字体/图片/模板加载；PDF 中文替换使用本机 C:/Windows/Fonts/simhei.ttf。

## 原件保护

- 处理前后计算并比对源文件 SHA-256，不一致立即停止并隔离。
- 只读属性下仍可处理（已测试），证明源码不写原件。
- 重复运行哈希稳定（已测试）。

## 导出门禁

- 唯一导出路径 task_manager.run()/finalize()：必须真实审计通过（report is task.audit、findings 非空、输出存在、源哈希一致）才复制到 output。
- 审计异常/无法检查/覆盖不足/发现残留 → 一律不导出并隔离。
- 不支持格式、加密文件、宏、外部链接、OLE、表单字段、嵌入图像敏感文字 → 明确拒绝。

## 独立审计

- 审计重新读取实际输出文件（文本 + OCR + 元数据 + 全部 XML 部件），不信任处理模块的成功标志。
- 高风险正则（身份证/手机/固话/邮箱/护照/银行卡）独立于候选清单，即使候选被人工排除仍可拦截。
- “未发现残留”不等于绝对安全：报告与界面均明确提示。

## 残余风险

- 无文字的图形印章/签名/二维码/条码/照片人脸不自动识别（需人工复核）。
- 审计与 OCR 无超时（极端挂起风险，不影响导出安全性）。
- 单字符自定义敏感词独立复查按长度≥2 过滤。
- 图表缓存等复杂对象依赖“全 XML 部件残留扫描”兜底，未逐对象语义处理。
