# LocalDocMask — 本地文件脱敏工作台

在 Windows 本地运行的桌面软件，对 PDF / DOCX / XLSX / XLSM / 图片（PNG/JPG/JPEG/TIFF/BMP）中的敏感信息进行识别与脱敏。

核心承诺：原件只读、数据不出本机、审计不通过不导出。

## 一、环境（实测）

- Windows 10 专业版 19045 x64，内存 64GB
- Python 3.11.16（项目虚拟环境 .venv，用 uv 创建，与系统 Python / Conda 隔离）
- Ollama 0.33.2，模型：qwen3.5:9b、qwen3-embedding:4b
- 磁盘：C/D/E 盘空间充足；输出与中间文件默认放在项目 data/ 目录下

## 二、启动

1. 双击 启动.bat（或命令行执行）。
2. 界面为简体中文，左侧配置、右侧查看候选与审计报告。

### 首次安装依赖（通常已完成）

    uv venv --python 3.11.16 .venv
    uv pip install --python .venv/Scripts/python.exe -r requirements.txt

## 三、使用流程

1. 选择文件：点击“添加文件”，可多选。
2. 配置：选择脱敏模式（A 统一掩码 / B 一致性虚构替换）、掩码字符、敏感类别、自定义敏感词 / 企业名单 / 人员名单、可选本地模型辅助。
3. 只读扫描：点击“① 只读扫描”，右侧表格查看敏感候选。
4. 人工复核：勾选 / 取消“包含”，可修改“替换值”，可“排除选中”。
5. 处理 + 审计：点击“② 处理 + 独立审计”，执行脱敏 → 独立审计 → 通过才导出。
6. 批量：点击“③ 批量自动处理（全部确认）”一键处理全部文件。
7. 输出在 data/output/，审计不过的文件进入 data/quarantine/。

## 四、两种脱敏模式

- 模式 A（统一掩码）：敏感内容替换为 ****（或自定义掩码），默认彻底删除。
- 模式 B（一致性虚构替换）：公司名→虚构公司名、姓名→虚构姓名；同一任务内相同实体一致；不同任务独立映射；映射表仅存内存、绝不落盘；不依据真实信息生成虚构名。

## 五、识别能力

- 身份证号（校验位/出生日期校验）、护照号、手机号、固定电话、邮箱、银行卡号（Luhn 校验）、详细地址、客户/员工/供应商/合同/项目等编号。
- 公司名（正则 + 企业名单 + 本地模型）、姓名（人员名单 + 本地模型）。
- 自定义敏感词（每行一个）。
- 图片/扫描件/PDF 内嵌图像文字经 RapidOCR（本地离线）识别。
- 本地模型（qwen3.5:9b）仅提供候选实体，不参与最终安全判定，输出必经程序校验。

## 六、安全设计

- 原件只读：处理前后计算并比对源文件 SHA-256；绝不覆盖/删除/修改原件。
- 真正删除：
  - PDF：删除相关文本对象，清除元数据/附件/批注；扫描页对 OCR 区域做像素级红化。
  - DOCX：替换段落/表格/页眉页脚/文本框文本，清除批注/修订隐藏文本/文档元数据。
  - XLSX/XLSM：替换全部工作表（含隐藏）单元格，清除批注/超链接/图片；含宏或外部链接则禁止导出。
  - 图片：像素级覆盖删除，统一输出 PNG。
- 独立审计：与处理模块分离，重新提取输出文本、重新 OCR、检查元数据/隐藏内容/附件/宏；任何残留、无法检查、覆盖不足均禁止导出。
- 失败关闭：审计不通过 / 源文件被改动 / 无法确认安全 → 一律进入隔离目录，不导出。

提示：“未发现残留”不等于绝对不存在敏感信息，请对重要文件进行人工复核。

## 八、测试

    .venv/Scripts/python.exe -m pytest tests -v

当前测试套件 17 项全部通过（检测、掩码一致性、四种格式端到端、隐藏工作表/批注、审计发现残留、源文件哈希校验、不支持格式拒绝）。

## 九、已知限制

含宏的 XLSM、外部链接、密码保护文件、图文混排页中的印章/签名等场景默认阻止导出或提示人工复核，详见 docs/未完成安全功能清单.md。
