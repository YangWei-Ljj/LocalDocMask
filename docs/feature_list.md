# LocalDocMask 功能清单

> 当前发布状态的唯一来源是 `dist/t9-evidence/release-summary.json`。本文件只描述能力与工程实现，不维护第二套发布结论。

## 识别与复核

| 能力 | 当前状态 |
|---|---|
| 身份证、手机号、银行卡、邮箱等高精度规则 | 已实现并有自动化测试 |
| 公司名、姓名、地址上下文融合 | 已实现，低置信候选转人工复核 |
| 本地中文 NER | 默认启用批准模型；模型缺失、损坏或推理失败时 degraded/失败关闭 |
| 公共实体和人工复核 | 已实现，未裁决项阻断导出 |
| 批量确认/排除 | 必须经过复核状态事件，不得绕过未裁决项 |
