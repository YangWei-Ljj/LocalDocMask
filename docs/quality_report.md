# LocalDocMask 质量评测报告

> 本文件是质量评测报告，不是发布状态来源。当前候选发布状态唯一来源：`dist/t9-evidence/release-summary.json`。

## 1. 评测定位

评测数据包括历史 101 条小规模语料和 600 条合成语料，用于验证规则、词库、上下文融合、可选 NER、复核率和抑制行为的回归稳定性。

这些数据全部为合成或受控测试数据，不能外推为真实文档生产精度，也不能替代外部验证。

## 2. 固定发布评测

固定套件：`synthetic-recognition-v1`

门禁检查：

- suite 与样本 SHA-256 完整；
- 执行状态必须为 completed；
- 质量状态必须为 passed；
- Recall、F1、抑制准确率和安全关键样本不得越过基线容忍度。

详细结果由 `scripts/eval_gate.py` 生成，保存在 `evaluation/reports/t9-release-gate.json`。

## 3. 历史 NER 对比

历史评测同时记录 NER 未启用和启用路径，用于评估人名/公司名召回与地址碎片误报的权衡。

- 未启用 NER 的旧结果仅代表历史基线；
- 当前候选默认启用批准本地 NER 模型；
- NER 只增加低权重候选，不能直接决定导出；
- 仅模型来源的上下文实体进入人工复核；
- 模型缺失或推理失败时健康状态 degraded，任务失败关闭。

## 4. 300 条与 600 条合成语料

历史报告中的 101 条和 600 条合成评测数据继续保留为质量证据，包括 TP/FP/FN、Precision、Recall、F1、复核率和抑制准确率。

使用约束：

- 合成语料指标不得宣称真实生产精度；
- 历史 F1=1.0 类结果只适用于对应固定合成集；
- 当前候选的通过/失败状态不得复制到本报告；
- 发布结论必须以 `release-summary.json` 为准。

## 5. 当前工程验证补充

当前测试还覆盖：

- 硬超时与子进程回收；
- 文件准入与原子导出；
- 审计 JSON 自包含与脱敏；
- SBOM 运行时依赖闭包；
- PyInstaller 打包后 DOCX/XLSX/PNG OCR/失败 quarantine E2E；
- 事件链、数据库恢复与外部验证门禁。

具体测试数量与进程退出码记录在对应批次 evidence 中，不在本报告维护固定数量。
