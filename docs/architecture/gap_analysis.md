# 差距分析矩阵：RepoMind vs LocalDocMask

> 版本：v1.0 日期：2026-10-26
> 依据：`docs/project_audit/repomind_baseline.md`、`docs/project_audit/localdocmask_current_state.md`
> 说明：对标的是"工程成熟度"（组织、质量、可维护性、可展示），而非机械复制技术栈或业务架构。

## 1. 总体差距矩阵

| 维度 | RepoMind（实测） | LocalDocMask（实测） | 差距 | 目标动作 |
|---|---|---|---|---|
| 模块组织 | 前后端分层 + services 子域清晰 | 扁平单包 14 文件，空目录占位 | 中 | 分层包（ADR-001） |
| 依赖方向 | 路由→schema→服务→数据 | GUI 直接 new 具体实现 | 中 | 端口 + 构造注入 |
| 配置管理 | pydantic-settings + .env 三套 | 全硬编码，config/ 空 | 中 | YAML + dataclass 校验（ADR-006） |
| 日志 | basicConfig（也偏弱） | 无 logging，异常被吞 | 中 | 结构化日志+脱敏（ADR-008） |
| 数据持久化 | PostgreSQL 29 表 | 全内存，无恢复/幂等 | 中 | SQLite（ADR-005） |
| 扩展机制 | Skill Runtime、DAG 编排、工具注册表 | 无 | 中 | 仅借鉴"注册表/契约"思想，不照搬 Skill/DAG |
| AI 能力 | 双栈 LLM + 多 Agent + 混合 RAG | 单一 Ollama 候选，仅辅助 | 中性 | 保持克制，补上下文判定（ADR-003/007） |
| 上下文工程 | 24K 预算五段、压缩 | 无 | 低-中 | 桌面端按需，不设复杂预算 |
| 评测体系 | RAGAS 五指标 + 在线回归 | 无标注集、无量化指标 | 中 | 标注集 + P/R/F1 等（evaluation） |
| 测试规模 | 后端 27 文件 / 5110 行 | 42 用例全过 | 中 | 补单元/集成/安全/异常/UI |
| 安全边界 | 草稿化、权限、密钥加密 | 哈希门禁、回环、独立审计、失败关闭 | 具优势 | 保留并增强（隐藏内容、映射保护） |
| 部署运行 | 脚本群 + 运行手册 + compose | 2 个 bat，无环境检查 | 中 | 环境检查脚本 + 运行手册 |
| 文档体系 | README/手册/架构/API/示例 | README 5.5KB + 少量 docs | 中 | 完整文档集（阶段9） |
| 演示能力 | 4 截图 + 种子数据 + 演示仓库 | 无演示脚本/截图 | 中 | 可重复演示流程 + 合成数据 + 截图 |

## 2. 应保留的 LocalDocMask 既有优势（不推翻）

1. 端到端安全门禁：原件 SHA-256 前后绑定、输出哈希绑定、finalize 失败关闭。
2. 独立审计器：重新提取文本/OCR/元数据/隐藏部件，不读处理期内存。
3. 网络边界：Ollama 强制回环、禁代理、模型输出仅候选。
4. 逐项处理状态机：redact → 失败 → delete → 验证。
5. 已修复的 SEC-001~008 与 42 项通过测试。

## 3. 可借鉴的 RepoMind 实践（按性价比）

1. 契约/注册表思想：embedding 三元组校验、工具命名空间注册 → 迁移为"端口契约 + 格式注册表 + 校验"。
2. 降级透明化：依赖不可用明确标注 degraded，不静默降级。
3. 评测闭环：固定评测集 + 指标 + 失败可复跑/对比 → 迁移为 evaluation 包。
4. 运行手册与实际部署对账：带验证命令的 runbook。
5. 写操作草稿化：有副作用动作先确认（对应人工复核）。

## 4. 不应照搬的部分（及原因）

1. PostgreSQL / 29 表 / Milvus / 多 Agent / MCP：业务规模与服务化形态不同，过度工程化（ADR-007）。
2. 启动期手工 ALTER TABLE、create_all 自动建表：无版本化、易漂移 → 本项目用显式 schema 版本 + 轻量迁移。
3. 假鉴权、无 lock、前端零测试、无 CI：这些是 RepoMind 自身短板，不引入。

## 5. 分维度成熟度目标（不设虚构阈值）

| 维度 | 目标 | 验证方式 |
|---|---|---|
| 识别质量 | 建立标注集与按类型/文件/路径分组的基线，再定目标 | 真实评测，记录规模与局限 |
| 安全 | 红线零违反：原件不变、无外传、失败关闭、无残留 | 安全测试 + 独立审查 |
| 可靠性 | 取消/超时/损坏/并发/恢复均有处理与测试 | 稳定性测试 |
| 可维护性 | 分层、配置、日志、持久化、文档一致 | 代码走查 + 文档对账 |
| 可演示 | 一键可重复演示 + 合成数据 + 截图 | 实际演练 |
