# LocalDocMask 未完成安全功能清单

> 下列能力当前未可靠实现。按“失败关闭”原则，涉及这些场景时软件会提示并禁止导出 / 要求人工复核，绝不静默放行。

## 已修复（上一轮验收）

- SEC-001：本地模型请求强制回环地址 + 禁用代理。
- SEC-002：导出门禁不可伪造/空报告绕过。
- SEC-003：DOCX 脚注/尾注已脱敏并纳入审计。
- SEC-004：DOCX 嵌入图像检测到敏感文字即阻止导出，审计复查图像。
- SEC-005：XLSX OLE 嵌入对象检测并阻止导出。
- SEC-006：PDF 表单字段检测并阻止导出。
- SEC-007：审计高风险规则补全护照号/固定电话，DOCX/XLSX 全 XML 部件残留扫描。
- SEC-008：DOCX 自定义属性清除。

## 仍需人工复核 / 未实现

| 序号 | 项目 | 当前行为 | 风险 |
|---|---|---|---|
| 1 | 无文字的图形印章/签名/二维码/条码/照片人脸 | 不自动识别，提示人工复核 | 图形化敏感内容未覆盖 |
| 2 | 审计/OCR 超时 | 无超时，极端情况可能挂起（不会因此导出） | 体验受影响 |
| 3 | GUI 取消操作 | 未提供取消按钮 | 长任务无法中止 |
| 4 | 单字符自定义敏感词独立复查 | 掩码生效，但审计按长度≥2 过滤（数字类不受影响） | 极小概率漏复查 |
| 5 | XLSX 图表缓存文本逐对象语义处理 | 依赖全 XML 部件残留扫描兜底 | 兜底覆盖但不逐对象 |
| 5b | PDF 表单字段 / XLSX OLE / 宏 / 外部链接 | 检测到即阻止导出（失败关闭） | 未逐对象删除 |
| 5c | DOCX 嵌入图像敏感文字 | 已实现像素级删除 + 删除验证（本轮新增） | 仅限 PNG/JPEG 可像素处理的图像 |
| 6 | 公司/姓名简称与全称的实体统一 | 按精确字符串映射 | 语义一致性有限 |
| 7 | 本地模型幻觉自动过滤 | 模型仅作候选，人工确认 | 依赖人工复核兜底 |

## 处理原则

- 任何“无法确认安全”的环节，最终状态均为 无法确认安全 / 审计失败 / 等待人工复核，文件进入 data/quarantine/，不会导出。
- “未发现残留”不代表绝对安全，重要文件请人工复核。
