# LocalDocMask 用户操作手册

> 面向第一次使用本软件的同事。你不需要懂代码，按下面步骤操作即可。
> 软件的设计原则是：**你的原始文件永远不会被改动；拿不准的地方它会停下来问你，而不是擅自决定。**

---

## 0. 在开始之前，请记住三句话

1. **原件只读**：你添加进去的原文件，软件只会读取，不会修改、删除或覆盖它。
2. **先扫描、后复核、再导出**：不要跳过"人工复核"这一步。
3. **拿不准就不导出**：如果某个文件显示"待复核""隔离""失败"，它就**不会**被导出成功，这是保护你，不是出错。

---

## 1. 添加文件（左侧第 1 区）

1. 双击 `启动.bat` 打开软件。
2. 在左侧"**1. 选择文件**"区，点"**添加文件**"。
3. 在弹出的窗口里选中一个或多个文件（按住 Ctrl 可多选），点"打开"。
   - 支持：PDF、Word（.docx）、表格（.xlsx / .xlsm）、图片（.png / .jpg / .jpeg / .tif / .tiff / .bmp）。
4. 添加的文件会列在"文件"表格里，"状态"列初始显示"尚未处理"。
5. 加错了可以点"清空"移除整批；选中某行再扫描即可只处理它。

> 文件过大（默认上限 50MB）或格式不支持时，软件会弹提示并拒绝添加——这是正常的保护。

---

## 2. 选择脱敏模式（左侧第 2 区）

| 模式 | 效果 | 什么时候用 |
|---|---|---|
| **模式 A：统一掩码** | 敏感内容全部替换成 `****` | 只要对外不可读、不需要看懂替换后内容 |
| **模式 B：一致性虚构替换** | 公司名换成虚构公司名、人名换成虚构人名；**同一个真实名字在一批文件里会换成同一个假名字** | 要对外演示/发测试样例，且希望文档里前后称呼一致、读得通顺 |

- "掩码字符"一般保持 `****` 即可。
- 模式 B 跨文件一致只在**同一批次**内成立；不同批次之间映射会重新开始，且不会保存成文件。

---

## 3. 配置敏感类别与词库（左侧第 3 区）

- **公司/企业名（正则）**：勾选后会自动尝试识别公司名。它可能误报短标签（如"内部公司"），但误报只会进入"待复核"，不会被自动遮掉。不想用可以取消勾选。
- **自定义敏感词**：每行一个。例如你单位内部的项目代号、系统名。
- **企业名单**：每行一个。这些会被当作**确认要脱敏**的内部企业名。
- **人员名单**：每行一个真实人名。名单里的名字会被识别出来。

> 这些设置在你点"执行"时生效；改完词库后最好重新扫描一次。

---

## 4. 本地模型（左侧第 4 区，可跳过）

- 这里显示本机 Ollama 是否连接。没装 Ollama 也能正常使用。
- 只有当你确实在本机跑着 Ollama 并勾选"启用本地模型辅助识别"时，它才会额外帮忙找公司名和人名；
  模型说的只算"候选"，最终遮不遮仍由规则和你决定。**模型不会把你的文件传到网上。**

---

## 5. 只读扫描（左侧第 5 区）

1. 点"**① 只读扫描（三档分流）**"。
2. 软件在后台解析文件并找敏感信息（图片/PDF 里的文字会用本地 OCR），不做任何修改。
3. 完成后，右侧"**6. 敏感候选**"表格会列出每条命中，每行包括：

   | 列 | 含义 |
   |---|---|
   | 包含（勾选框） | 打勾=这条要脱敏；取消=不脱敏 |
   | 决策 | 自动确认 / 待复核 / 已抑制（见下） |
   | 风险 | 低 / 中 / 高 / 严重 |
   | 类别 | 身份证号、手机号、公司名、姓名… |
   | 原文 | 命中的敏感内容 |
   | 替换值 | 脱敏后变成什么（可直接修改） |
   | 位置 | 在第几段/第几页/哪个单元格 |
   | 来源 | regex / dict / ocr / ollama / blacklist… |
   | 置信度 | 0~1 的把握程度 |
   | 判定理由 | 为什么软件这样判定（重要，请扫一眼） |

4. 表格行会**用颜色区分**：
   - 绿色 = 已确认脱敏；
   - 黄色 = 待你复核；
   - 灰色 = 已抑制（不脱敏，通常是"我们公司""本公司产品"这类泛指）。

---

## 6. 阅读候选与决策：三档是什么意思

- **自动确认（绿色）**：软件比较有把握，会直接脱敏（例如校验通过的身份证、银行卡、手机号）。
- **待复核（黄色）**：软件拿不准，**停下来等你决定**。常见于公司名、人名、公开企业名。
- **已抑制（灰色）**：软件判断这不是敏感信息，不处理（例如"我们公司""集团公司"这种没有具体专名的说法）。

> 你随时可以推翻软件的判断：勾选就是要脱敏，排除就是放行。

---

## 7. 人工复核（候选表下方按钮）

选中一行或多行后：

- **确认脱敏（选中）**：把选中项设为要脱敏。
- **排除/放行（选中）**：把选中项设为**不脱敏**（例如它误判了一个真实合作方的名字，你不想遮）。
- **全选 / 全不选**：批量处理。
- **直接改"替换值"列**：双击某行的替换值，可以改成你想要的内容。
- **刷新预览**：右侧"脱敏预览"页会实时左边显示原文、右边显示脱敏后的样子。

**关键安全规则**：如果还存在黄色"待复核"项你没有处理，软件在导出时会**拦下这个文件**，不会让它导出。这是故意的。

---

## 8. 处理 + 独立审计

确认好候选后，点"**② 处理 + 独立审计（复核门禁）**"。软件会自动做：

1. 对已确认的条目做脱敏；
2. 逐条复查脱敏结果里还残留没有；如果某条残留，会自动进入"删除"流程并再验证一次；
3. 由一个**独立的复查程序**重新打开输出文件，重新读文本、重新 OCR、检查元数据/隐藏内容；
4. 全部通过后，文件进入成功目录；否则进入"隔离"。

你可以在"**独立审计报告**"页看到复查结论。

---

## 9. 批量处理与取消

- 点"**③ 批量自动安全处理**"会依次处理整批文件。
- 规则：**含待复核项的文件会自动挂起、不导出**；某个文件失败不会影响其他文件。
- 处理过程中点"**取消**"会停下，已完成的保留。
- 进度条会显示当前文件名和阶段。

---

## 10. 导出脱敏文件

1. 只有状态为"**审计通过，可以导出**"的文件，"**④ 导出脱敏文件到指定位置…**"按钮才可用。
2. 点它，选一个保存位置，确认即可。
3. 想直接看自动保存的成功副本，点"**打开成功目录**"（在 `data/output/success/`）。

> 导出的是脱敏后的新文件；你的原文件始终原封不动。

---

## 11. 查看任务中心 / 历史与结果分页

右侧底部有几个标签页：

- **脱敏预览（原文 | 脱敏后）**：左右对照。
- **独立审计报告**：复查结论与每条发现。
- **成功结果**：通过门禁的文件清单（识别/脱敏/删除数量、哈希前 8 位）。
- **复核/失败**：未裁决项、失败原因、未决条目明细。
- **隔离文件**：被失败关闭移到隔离目录的文件及原因。
- **任务中心/历史**：所有任务按时间列出（状态、模式、识别/脱敏/删除数）；选中一行可点"打开选中产物所在目录"。

---

## 12. 失败、隔离、崩溃后怎么处理

| 现象 | 含义 | 你该怎么做 |
|---|---|---|
| 状态"等待人工复核" | 有黄色待复核项没处理 | 回到候选表逐条裁决后再处理 |
| 状态"无法确认安全"/"审计失败" | 复查发现残留、输出不可读或被改动 | 文件已进隔离目录，**不要用**；检查后重新处理或人工核对 |
| 状态"已中断" | 上次处理到一半软件退出，且已产出中间文件 | 不自动信任该产物；可在历史里查看后决定是否重跑 |
| 隔离目录里的文件 | 失败关闭的产物 | 仅用于排查，**不要对外发送** |
| 含宏/外部链接/OLE 的表格、带表单字段的 PDF | 软件无法可靠清除这些内容 | 被阻止导出；请人工处理或换格式 |

- 点"**清理临时文件**"会清空处理中间目录（`data/processing/`），不影响原件和成功产物。
- 软件异常退出后重新打开，它会自动把上次卡在"处理中"的任务重新归类（能安全重试的重新排队，已产出但未审计的标记为"已中断"）。

---

## 13. 安全注意事项

- 你的文件和映射表默认**只保存在本机**；软件不会上传。
- 数据库和日志里只存掩码后的内容，不存完整敏感原文。
- 即便显示"未发现残留"，也**不等于绝对干净**；对外发送重要文件前请人工抽查。
- 隔离目录和 `data/` 下的中间文件可能仍含敏感内容，清理前不要外发。
- 本地模型（Ollama）默认关闭；如启用，请确认它跑在本机，不要把地址填成外网地址。

---

## 14. 常见问题

**Q：我误排除了一个真要遮的内容，会怎样？**
A：它不会被脱敏。请在处理前重新勾选；一旦文件已导出成功，需要重新跑一遍。

**Q：模式 B 里同一个人在两个文件里被换成不同名字？**
A：模式 B 的一致性只在**同一批次**内共享。请在同一次批量运行里处理这批文件。

**Q：图片里的印章/红字被遮掉了吗？**
A：软件会对 OCR 识别出文字的区域做黑块；大面积红色印章只提示你人工复核，不会自动判断。

**Q：为什么一个文件就是导不出？**
A：几乎都是因为还有未裁决的待复核项，或复查发现残留。去"复核/失败"和"隔离文件"页看原因即可。
